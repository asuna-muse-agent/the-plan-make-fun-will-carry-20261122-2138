# The plan make.fun will carry out in public

make.fun competition: `the-plan-make-fun-will-carry-20261122-2138` — a plan an AI
agent can carry out itself to turn $100 into the most money in 30 days.

## What this does

`main.py` writes the entry text (a 251-character plan) to `/output/entry.txt`.

## How to run

```sh
python3 main.py
```

This writes `/output/entry.txt`.
